# Zorinto Fonts Homebrew Tap

Official Homebrew tap for installing Zorinto developer fonts on macOS.

## Available Fonts

- **Hari Mono**: Open-source monospaced typeface for terminals and editors, built with Iosevka in the spirit of Berkeley Mono.
- **Hari Mono Nerd Font**: Patched with over 10,000 developer icons for shell prompts and code tools.

## Installation

Add this tap:

```sh
brew tap zorinto/fonts
```

Install standard Hari Mono:

```sh
brew install --cask font-hari-mono
```

Install Hari Mono with Nerd Fonts:

```sh
brew install --cask font-hari-mono-nerd-font
```

## Documentation
